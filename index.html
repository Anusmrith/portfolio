1-Click Windows Setup & Launch

Run M.A.N.I. locally on your Windows 10 or 11 machine. Open PowerShell, Command Prompt, or Windows Terminal, and paste this single command:

git clone https://github.com/Anusmrith/m.a.n.i.-AI-assistant.git && cd m.a.n.i.-AI-assistant && start_mani.bat
What Happens Next Automatically
  • 1
    Virtual Environment: start_mani.bat automatically sets up an isolated Python virtual environment (.venv).
  • 2
    Zero-Fuss Dependencies: Installs all requirements (SpeechRecognition, edge-tts, pyautogui, psutil, google-genai) without polluting global Python.
  • 3
    Launch HUD & Voice Loop: Pops open the cyberpunk Tkinter desktop companion window and begins continuous voice listening immediately.
  • 4
    Optional Gemini Key: Add your free Google Gemini API key to .env for deep generative reasoning, or run 100% offline for instant local automation.
